# 权威基线与判据

## 1. 为什么要重新冻结基线

旧项目的 GATE 宏与文字材料使用了两套不一致的物体坐标：

- 实际宏中的水泥为 `z=[-100,0] mm`；
- 实际宏中的铁为 `z=[-150,-100] mm`；
- 旧分析却按铁 `[-125,-75] mm`、水泥 `[-225,-125] mm` 解释结果。

因此旧结果中 `z≈-2.5 mm` 的峰本来就在水泥上表面附近，不能再据此判断
“重建跑到了错误层”。本版本以实际宏的坐标系为基础，并先把物体简化为单一
100 mm 水泥板，避免铁层和空气槽影响第一轮物理验证。

## 2. 唯一坐标系

| 部件 | 全局 z 范围或中心 | 说明 |
|---|---:|---|
| 水泥上表面 | `0 mm` | 深度定义为 `depth=-z` |
| 水泥板 | `[-100,0] mm` | 第一轮基线物体 |
| D1 环形 GAGG | 中心 `17.5 mm`，范围 `[10,25] mm` | 背散射成像探测器 |
| 双光子源 | `17.5 mm` | 位于 D1 中央孔轴线上 |
| D2 GAGG 阵列 | 中心 `60 mm`，范围 `[50,70] mm` | 标记/准直探测器 |

D2 的实际阵列节距是 `1.00 mm`，不是晶体宽度 `0.93 mm`。50 个重复单元覆盖
约 50 mm 的读出范围。

## 3. 第一轮必须验证的量

### 3.1 文件与真值

- ROOT 中存在 `Hits_BSdetector` 与 `Hits_crystal`。
- `pet_data.latest_event_ID+1` 与命令行给定初级事件数一致。GATE 9.4.1
  实测会把最后一个从 0 开始的事件编号同时写入
  `pet_data.total_nb_primaries`，因此分析程序保留原值并另存
  `primary_event_count` 用于归一化。
- D1 Hits 的 `nPhantomCompton` 不再全为 0。
- D1 Hits 的 `comptVolName` 能出现 `concrete`。
- 真值 actor 文件包含 `EventID`、`RunID`、`ParentID`、`X/Y/Z`、
  `CreatorProcess`；至少能找到由 Compton 过程产生的电子，并以
  `ParentID` 对应 D1 Hits 的 `primaryID`。
- 初始化日志确认使用项目内 GAGG 定义：
  `Gd3Al2Ga3O12`、密度 `6.63 g/cm3`，不依赖虚拟机中手工改过的材料库。

### 3.2 能谱

- D2 聚合事件能谱应在 511 keV 附近出现全能峰。
- 对 511 keV 入射光子，单次康普顿散射后的光子能量为

  \[
  E'=\frac{511}{2-\cos\theta}\ \text{keV}.
  \]

- 对几何意义上的背散射 `90°≤θ≤180°`，理论区间是
  `170.33≤E'≤255.50 keV`。
- 低于 170.33 keV 的 D1 聚合能量不能由“单次散射光子完全吸收”解释，
  应归为部分能量沉积、多次散射或污染事件，不能通过裁剪
  `cosθ` 强行变成 180°。

### 3.3 重建

- 闭式解只对运动学和几何均可解的事件返回坐标。
- 第一轮水泥板只用于检查重建分布、深度偏差与真值闭环；
  水泥板分布的 FWHM 不叫“系统分辨率”。
- 后续薄层/细杆体模中，才报告 PSF FWHM、定位偏差、双目标可分辨性和 MTF。

## 4. 灵敏度口径

先报告最稳健的无量纲效率：

\[
\epsilon=\frac{N_\mathrm{selected}}{N_\mathrm{primary}}.
\]

若一个初级事件代表一次双光子衰变，且处于无死时间、无堆积的低计数率条件，
则可换算：

\[
S\,[\mathrm{cps/MBq}]=10^6\epsilon.
\]

任何加入死时间、偶然符合或活度依赖的模型都必须单独标注，不能与上述理想真符合
灵敏度混为一谈。

## 5. 合格后再做的扫描

扫描顺序固定为：

1. D1/D2 能量窗；
2. D2 给出的入射角；
3. 由 D1 能量得到的散射角；
4. D1 外半径与方位扇区；
5. D2 中心、环带、象限等读出区域；
6. 选出 Pareto 候选后，用真实改变 D1 半径的 GATE 宏复算确认；
7. 在 Concrete、Water、Iron 的相同标准体模上比较。

每个点至少同时输出事件效率、空间分辨率/定位偏差以及 CNR 或目标可检测率。
