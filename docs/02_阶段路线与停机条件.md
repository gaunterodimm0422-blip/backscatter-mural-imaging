# 阶段路线与停机条件

## 阶段 A：宏与数据结构

完成条件：

- 冒烟测试无 GATE fatal error；
- Hits、phantomSD 和 truth actor 三类信息齐全；
- 主机端分析能一键生成事件表、符合表、重建表和 JSON 审计。

未满足时不进入大样本模拟。

## 阶段 B：能谱与基础物理

完成条件：

- D2 511 keV 全能峰位置合理；
- D1 的真单次水泥康普顿事件主要符合 170.33–255.50 keV 运动学区间；
- 部分沉积、多次散射、Rayleigh 和无水泥散射事件能够分开计数；
- 运行初级事件数、随机种子、GATE 版本和宏哈希均有记录。

未满足时不把任何空间宽度称为分辨率。

## 阶段 C：标准分辨率体模

按 `configs/experiment_matrix.csv` 建立薄水泥层、细杆、双杆和边缘体模。

完成条件：

- 每个目标都有已知位置/尺寸或 actor 真值；
- 报告重建偏差、PSF FWHM、双目标可分辨性、MTF10/MTF50；
- 给出 bootstrap 或重复随机种子的统计不确定度；
- 深度曲线至少覆盖 10、30、50、70、90 mm。

## 阶段 D：水泥缺陷成像

建立水泥背景中的空气孔洞，联合改变孔径和深度。

完成条件：

- 输出目标区/背景区定义；
- 报告 CNR、对比恢复系数和检测概率；
- 给出“在给定初级事件数/活度与误报率下”的最大可检深度，
  不使用无统计条件的绝对“最大深度”。

## 阶段 E：筛选与分区

在同一原始数据上扫描能量窗、入射角、散射角、D1 半径/扇区和 D2 区域。

完成条件：

- 每个扫描点同时给出分辨率、偏差、CNR 和效率；
- 给出非支配的 Pareto 点；
- 明确区分“后处理选区”和“物理改变探测器”的结果；
- D1 缩径候选必须用改变真实几何的 GATE 复算确认。

## 阶段 F：材料与最终尺寸

在相同体模尺寸、深度、初级事件数和重建规则下比较 Concrete、Water、Iron。

最终建议至少包含：

- D1 推荐外半径与质量/有效计数损失；
- D2 推荐有效区域或分区读出方法；
- 深度分辨率、横向分辨率、灵敏度和缺陷 CNR 的适用范围；
- 未建模项：电子学、死时间、堆积、偶然符合、材料不确定性等。
