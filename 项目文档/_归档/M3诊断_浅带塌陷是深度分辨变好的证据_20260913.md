# M3 诊断：0–8 带对比度塌陷 = 深度分辨变好的直接证据（已结案）

日期 2026-09-13 · 上游 `M3结果_STAGE-a_主判据全过但预言判据未过_20260913.md`

---

## 一、结论

**M3 的 0–8 mm 重建深度带里，单次散射事例的对比度是 `−0.56 ± 1.4 %`，即精确地等于零。**

这正是物理要求的：空鼓在真实深度 20–40 mm，一个**真正**在 0–8 mm 处散射一次的光子，入射腿和出射腿都不经过空鼓层，**它不可能携带任何空鼓信息**。M2 那 8.79 ± 1.8 %（离零 4.9σ）是深度重建不准造成的**泄漏假信号**。

所以：**浅带对比度塌下来不是性能退化，是深度分辨变好之后假信号消失了。**

## 二、机制的量化证据

### 2.1 杠杆臂（GATE 真值，参照场）

```
|d| = |H − S| 中位      50.72 → 39.53 mm      比 = 0.779
深度误差半宽(84−16)/2   15.10 → 10.93 mm      比 = 0.724
|深度误差| 中位          8.81 →  6.30 mm      比 = 0.715
```

`t = |d|·sin(θ−α)/sin θ` ⇒ `dt/dθ = |d|·sinα/sin²θ`，**深度误差应当正比于 `|d|`**。实测两个比值 0.779 与 0.724 相符——D1 从离物体 10 mm 压到 2.5 mm，杠杆臂短 22%，深度重建准 28%。**机制成立。**

这同时解释了本轮其它三个现象：`T` 从 326.7 翻到 632.6；25–35 带对比度 +9.9 pp；边界过渡宽度 `w` 从 2.20 收到 1.51 mm。

### 2.3 0–8 带塌陷的分解

```
单次散射的贡献   +6.74 → −0.46 pp     变化 −7.20 pp     占塌陷的 85%
多次散射的贡献   +4.05 → +2.77 pp     变化 −1.28 pp     占塌陷的 15%
合计             10.79 →  2.31 pp     变化 −8.48 pp
```

**主因是单次散射的深度泄漏消失，不是多次散射减少。**

> **更正我上一轮的判断**：我说过"泄漏只解释了一半，剩下一半是多次散射"。那是基于 `c_b ∝ f_void` 这个线性近似推的。直接测出来之后，这个近似不成立（`c_b` 里还有来自 40 mm 以下的负贡献在抵消），**真实答案是泄漏解释了 85%**。

## 三、两条新的、可以写进报告的性质

### 3.1 单次散射的对比度随深度单调上升——这是深度分辨的直接判据

```
M3 单次 c_b：  −0.6  →   9.0  →  30.8  →  37.9 %      单调上升
M2 单次 c_b：   8.8  →   8.8  →  33.5  →  26.8 %      深带回落
```

空鼓在 20–40 mm，所以"对比度随重建深度单调上升、且在浅带归零"是**深度分辨足够好**时必然出现的形状。M2 做不到（浅带有假信号、深带反而回落），M3 做到了。

**这个形状本身就是一条比 `T` 更直观的分辨力指标，建议纳入以后的判据。**

### 3.2 多次散射的对比度几乎与重建深度无关

```
M3 多次 c_b：  14.8  →  21.9  →  26.2  →  26.0 %
M2 多次 c_b：  17.4  →  22.2  →  20.1  →  22.8 %
```

多次散射事例的重建顶点与它实际在哪儿作用已经脱钩，所以它携带的是一个**与深度无关的平均空鼓信号**。这正是"它的重建深度没有意义"的签名。

多次散射的份额随深度带上升，两个构型几乎相同：

```
M2： 23.3% → 29.8% → 38.6% → 48.3%
M3： 18.7% → 28.0% → 38.5% → 48.6%
```

**最深的 25–35 带有将近一半是多次散射事例**——这给深带对比度设了一个上限：即使把多次散射全剔掉，那一带也只剩 51% 的事例，但对比度能从 32.2% 升到 37.9%。

## 四、必须写明的限制

1. **`d1_n_phantom_compton` 是 GATE 真值，不是可观测量。**上面的拆解只能用于机制判定，**绝对不能当成一条判选写进分析链**。真实测量里我们不知道一个光子在墙里散了几次。
2. 目前**没有已知的可观测代理**能把多次散射分出来。这与 L3-A 里 D2 的康普顿序列重建是两回事——那是探测器内部的多点沉积，这里是**幻影内部**的多次散射。是否存在可行的判选是一个开放问题，不要对导师承诺。
3. 真值顶点只记录到 40 mm 的泥层为止，**砂砾岩支撑体（40–140 mm）里的散射一个都没记**。所以任何"真深 > 40 mm 的份额"都显示为 0，那是假象；`diag_shallow_band.py` 输出里的"预言 c_b%"那一列因此是废的，不要引用。
4. `diag_shallow_band.py` 的自检（各带 N 应与 `analyze_mural_edge` 的 `ref_main` 列相等）**没有通过**，因为我在脚本里加了 `isfinite(truth_z_mm)`，把无真值的事例整个丢了（M2 丢 26.5%，M3 丢 26.2%）。第二个脚本 `diag_multiscatter.py` 用双比值，不受这个影响，本文的结论全部出自它。

## 五、事例级蒙卡的第五条失效

它给的 0–8 带 `f_void` 是 6.7% / 3.8%，GATE 真值折算到全体是 10.4% / 6.4%——**低估 1.6 倍**。加上此前四条（每初级选出率低估 33%、浅带对比度高估 10 倍、视场公式漏掉 D1 外半径、四带对比度全面高估），结论不变：

**`design/m2_predict.py` 这套事例级蒙卡在新构型下只能用来排序，不能用来定判据阈值。**以后凡是要冻结数值判据，阈值必须来自实测（M2/M3 的 GATE 数据），不能来自它。
