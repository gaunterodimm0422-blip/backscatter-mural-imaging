### 2.3 浅带塌陷诊断（本轮最重要的物理发现）

0–8 带的对比度从 M2 的 12.21 % 掉到 M3 的 2.40 %。查下来**不是性能退步，是深度分辨变好的直接证据**：

- **杠杆臂机制**：`dt/dθ = |d|·sinα/sin²θ`，深度误差正比于 `|d| = |H − S|`。D1 贴近被测面后 `|d|` 从 50.72 降到 39.53 mm（×0.779），深度误差半宽从 15.10 降到 10.93 mm（×0.724）。
- **双比值拆解**（按 GATE 真值 `d1_n_phantom_compton` 分单次/多次，`|x_head| ≤ 16.5 mm`）：M3 的 0–8 带单次散射对比度 **−0.56 ± 1.4 %**（占 81 %），多次 14.79 ± 2.6 %（占 19 %）；M2 同带单次 8.79 ± 1.8 %（占 77 %），多次 17.37 ± 2.9 %。
- 结论：塌陷的 **85 %** 来自单次散射泄漏消失（浅带里不再混进深处事例），15 % 来自多次散射变少。
- 附带：M3 的单次散射对比度**随重建深度单调上升**（−0.6 / 9.0 / 30.8 / 37.9 %），M2 不是（8.8 / 8.8 / 33.5 / 26.8 %）。多次散射的对比度与重建深度无关（14.8–26 %），且占最深带的 48.6 %。

**注意**：`d1_n_phantom_compton` 是 GATE 真值，**不能当筛选条件用**，目前也没有可观测的代理量。这是开放问题，不要对外承诺。

## 5. 会让你犯错的坑（务必读完再动手）

1. **D1 和 D2 极易搞反。**
   - `D1 = 背散射探测器`：GAGG 环，**贴近被测面**，M3 里 z ∈ [2.5, 12.5]（中面 7.5 mm），内半径 12.5、外半径 100 mm；能量分辨 8 % @511 keV，能窗 **180–250 keV**，位置分辨 **1.55 / 1.55 / 5.0 mm**。宏里叫 `BSdetector`。
   - `D2 = 标记探测器`：50 × 50 像素 GAGG 阵列（单元 0.93 × 0.93 × 20 mm），**在源的另一侧**，M3 里下表面 z = 42.5、中面 z = 52.5 mm；能量分辨 **12 %** @511 keV，能窗 400–600 keV，位置分辨 1.0 / 1.0 / 2.5 mm。宏里叫 `CoinDetector`。
   - **注意**：`BackscatterAnalysisConfig.h` 里的 `backscatter_center_z_mm = 17.5` 与 `tagging_center_z_mm = 60.0` 是**旧构型（M2）**的值，不要当成 M3 的。M3 对应的是 7.5 与 52.5。判断哪个是哪个，看的是"贴近被测面 = D1 = 背散射"这条，不是具体数字。
   - **我在成像算法说明里把 D1/D2 写反过一次，整份重写才改正。**
   - **导师需求文档的参数（D1 175–260 keV、D2 15 %、D1 1.5 / 1.5 / 5.0）不是仿真实际用的值。**写任何探测器参数前，查 `configs\m3_edge_main_20260912.json`，不要抄需求文档，也不要抄 `成像算法说明_20260912.docx`（那里还是错的）。

2. **事例级蒙卡 `m3_predict.py` 有六条已实测证伪的失效**：每初级选出率低估 33 %、0–8 带对比度高估 10 倍、视场公式漏了 D1 外半径、四带对比度全面高估（缺多次散射）、`f_void` 低估 1.6 倍、`k` 变化低估 5.2 倍。**只能用来排序，绝不能用来定判据阈值。冻结数值判据一律取自 GATE 实测。**

3. **`diag_shallow_band.py` 输出里的"预言 `c_b`%"那一列作废。** 它按 `isfinite(truth_z_mm)` 筛掉了约 26 % 事例，而真值深度只记录到 40 mm，所以 `f(真深 > 40) = 0` 是人为产物。浅带结论出自 `diag_multiscatter.py` 的双比值，与这一列无关。

4. **0–8 带的 `c_b` 随离轴距离上升（2.40 → 3.75 → 16.43 %）是拟合窗边缘的外推，不是真的对比度回升。** 0–8 带拟合窗只有 ±16.5 mm，`halfvoidx31` 的边界恰好落在 `u = −16`。旁证：离轴 −16 mm 档的浅两带，实墙侧已出视场，描述性双比值根本算不出来。**引用浅带数字必须连边界位置一起写。**

5. **成像图上标的"对比度"不是冻结分析的 `c_b`。** 前者是两侧直接求和的描述性双比值（保护带 ±6 mm，用满视场），后者是 ±16.5 mm 窗内的二项似然拟合。数值接近但不相等，逐条对照表在 `成像演示图…_20260914.md` 第四节。**正文一律用冻结分析的数。**

6. **计数率必须记两个数。** 每初级粒子 ×1.392，每真实湮没 ×0.859，真实测量时间只多 16 %。两者差一个 Ω/4π（45° = 1.8403 sr，35° = 1.1363 sr，比值 0.6175）。**只报一个数会得出相反结论。**

## 8. 用户的工作要求（硬性，不要违反）

- **用中文沟通。**
- 用户是**跨专业研究生，核技术基础较弱**：先给结论，再用通俗方式解释物理含义。
- 给导师的报告、PPT、图注**保持严谨科研表达**，不能把"图好看"当作"结果正确"。
- **不要夸大能力边界**。每次图或算法更新都要说明：数据来源、是否用了真值、参数如何选择、负对照结果。
- 改代码**必须用 apply_patch**；不要用 `git reset --hard`、`git checkout --` 或递归删除；保留已有文件和改动。
- **长时间的 GATE 模拟用户自己在 vGate 虚拟机终端跑**，你要给的是明确的命令、监控命令和结果判据，**不要代跑**。
- **不要偷懒**：输出结构化清单、表格、多条目名单时，每一条必须填到同样的完整度；已掌握的信息不能漏填，缺失的要明写"缺"，不能默默省略字段。交付前自己逐条核对一遍一致性。
- 给用户直接复制粘贴的文本，**必须逐字完整写出，禁止用省略号代替中间内容**。发现错误时先核对是不是自己上一轮写的，**不许把自己的错误说成是用户改的**。
- 主力机上**没有全局 Python**，跑脚本要写全路径 `E:\python3.12\python.exe`。
