## 远控机虚拟机（vgate@vgate-VirtualBox）

| 东西 | 路径 |
|---|---|
| GATE 宏与跑批脚本所在目录 | `/home/vgate/beisanshe/gate_bundle_20260910/gate` |
| 共享盘挂载点 | `/media/sf_vgate_shared`（= Windows 的 `D:\vgate_shared`） |
| **GATE 结果落点（SHARE_OUT）** | `/media/sf_vgate_shared/output` |

`run_mural_*.sh` 会把 `${SHARE_OUT}/${RUN_ID}/` 建出来再拷。
**脚本里的自动探测会拼成 `<挂载点>/beisanshe_v1/gate/output`，那是主力机的布局，在远控机上是错的**，
所以在远控机上必须显式给 `SHARE_OUT=/media/sf_vgate_shared/output`。

共享盘根目录下还有一个 `mural_ref_t10_L-15_0m_seed24091012`，那是 50 万事例的
廉价验证跑（`$((500000/1000000))` = 0，所以名字里是 `0m`），不是正式结果，别用。

## 远控机上的分析三步（出自 `D:\beisanshe\README_远控机分析环境.md`）

```
cd D:\beisanshe

C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe scripts\check_environment.py

C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe -m backscatter analyze ^
    --root "D:\vgate_shared\output\<RUN_ID>\hits.root" ^
    --truth "D:\vgate_shared\output\<RUN_ID>\hits_truth_mural.root" ^
    --config configs\<配置>.json ^
    --out-dir runs\<RUN_ID>

C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe scripts\apply_response_to_analysis.py ^
    --analysis-dir runs\<RUN_ID> ^
    --config configs\<配置>.json
```

`analyze` 只做到"理想 GATE 事件对"，**必须再跑 `apply_response_to_analysis.py`**，
所有正式数字都是在 `runs\<RUN_ID>\canonical_response\` 上算的。响应随机种子固定 24080601。

`check_environment.py` 的四项判据：闭式解自检通过；横向 y FWHM 与 4.146 mm 差 < 1%；
深度 z FWHM 与 38.317 mm 差 < 1%；bootstrap 95% CI 与 [3.29, 5.01] 差 < 3%。
**这一步不过就别在远控机上出正式数字。**

## 本会话犯过的路径错误（别再犯）

   "路径换成那台机器上的"——等于把活推给用户。远控机是
   `C:\Users\Administrator\AppData\Local\Programs\Python\Python313\python.exe`。
