## 一、结论

两张图都没有用真值去"帮"重建。真值只出现在图上的绿色参考线／参考框里，用来和拟合结果对照，**不参与任何一步计算**。

## 三、图上每一个量是怎么算的

| 量 | 口径 |
|---|---|
| 横坐标 `x` | 探测头坐标 = 重建点世界 `x` 减去该事例的源 `x`；三档探测头都在 −15 mm |
| 纵坐标 | **重建深度**，不是真深度 |
| 分箱 | 横向 3 mm（−36…+36，24 箱），深度 5 mm（0…60，12 箱） |
| 一维剖面的深度分组 | **就是冻结分析的四条带 0–8 / 8–15 / 15–25 / 25–35 mm**（npz 里的 `hb_r`/`hb_v`）；图二 (d) 用 15–25 与 25–35 的合并 |
| 比值 | 空鼓场计数 ÷ 参照场计数，**先按初级粒子数归一**（四档都是 4 M，归一系数 = 1.000） |
| 低统计截断 | 每箱参照计数 < **100** 的不画 |
| 色标（密度图） | 顺序型单色相，`vmax` = 两场合并后的 99.5 分位 = 2121 |
| 色标（比值图） | 发散型，**中点固定在 1.0 且为中性灰**，范围 0.6–1.4 |
| 图上标的"对比度" | 本图自算的**描述性双比值**：边界两侧各留 6 mm 保护带，两侧各自把该深度组的计数加起来再做比值，`c = 1 − 右/左` |
| 误差棒（剖面） | 泊松，`σ_r = r·√(1/n_void + 1/n_ref)` |
| 误差棒（标定点） | 各档自身的 68% 区间，**取自冻结分析 json 的 `xe_lo` / `xe_hi`，不是本图算的**：轴心 下 0.329 / 上 0.336，−8 档 下 0.396 / 上 0.431，−16 档 下 1.468 / 上 0.999 mm（不对称）。09-23 前版本误写成对称的 ±0.35 / ±0.45 / ±1.25 |

### 图二 (e) 的标定拟合带自检

脚本用三点无权拟合（与 M2 四点标定逐字同一套做法）现算 `k`、`b`、`r²`，并**断言必须复现冻结分析记录的值**，对不上直接抛异常、图作废：

```
k  = 0.9263 ± 0.0231      要求 |k − 0.9263| < 5e-4
b  = +0.037 ± 0.239 mm    要求 |b − 0.037|  < 5e-3
r² = 0.99938              要求 |r² − 0.99938| < 5e-5
残差 −0.107 / +0.213 / −0.107 mm
```

三条断言全过。误差棒只影响画出来的竖线，不进入这组无权拟合，所以 09-23 改误差棒后三个数一个没变。

| 轴心 | 8–15 | 10.09 % | 12.60 % |
| 轴心 | 15–25 | 32.90 % | 31.41 % |
| 轴心 | 25–35 | 37.46 % | 36.25 % |
| 离轴 −8 | 0–8 | 3.72 % | 3.75 % |
| 离轴 −8 | 8–15 | 8.66 % | 12.20 % |
| 离轴 −8 | 15–25 | 33.31 % | 32.06 % |
| 离轴 −8 | 25–35 | 35.55 % | 36.68 % |
| 离轴 −16 | 0–8 | **算不出来** | 16.43 % |
| 离轴 −16 | 8–15 | **算不出来** | 15.64 % |
| 离轴 −16 | 15–25 | 32.66 % | 37.43 % |
| 离轴 −16 | 25–35 | 32.60 % | 32.26 % |

两者算法不同：`c_b` 出自多深度带共享边界的二项似然拟合（拟合窗 ±16.5 mm），图上的是两侧直接求和的描述性双比值（保护带 ±6 mm，用满整个视场）。**正文和图注引用 `c_b` 时一律用冻结分析的数，不要从图上读。**

**一个新增的旁证**：离轴 −16 mm 档的浅两带，边界左侧（实墙侧）已经出了视场，描述性双比值**根本算不出来**（没有足够统计的箱）；而冻结拟合仍给出 16.43 % / 15.64 %。这说明那两个数完全是拟合模型在窗口边缘外推出来的，不是直接测到的对比度——与 `M3结果_STAGE-b…` 第六节"16.43 % 不能拿去和 main 档的 2.40 % 比较"的结论一致，且更直接。

## 五、另外两条不能乱引用的地方

1. **图一 (d) 的 0–8 带对比度 −0.13 %，这是好消息不是坏消息。** 真正浅层的单次散射事例对比度精确为零（`M3诊断_浅带塌陷…` 的双比值拆解给出 `−0.56 ± 1.4 %`），因为新构型杠杆臂短、深度分辨好，浅带里不再混进深处的事例。**引用时必须连这个解释一起写**，否则读起来像性能退步。

2. **比值图里 40 mm 以下那一片不是"空鼓延伸到了 40 mm 以下"。** 真值空鼓只有 20–40 mm。亏空之所以在纵向铺开到 45 mm 左右，是本构型深度误差半宽约 10.9 mm 造成的涂抹。**这正是本方法只报横向边界、不报深度的原因**，图注里作为正面论据写了出来，不要当成缺陷回避。
