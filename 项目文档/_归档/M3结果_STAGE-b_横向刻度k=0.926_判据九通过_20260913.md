### 5.2 改正后

> **这是 2 参数拟 3 点、只有 1 个自由度的样本内残差，必然偏乐观，不能当作对新测量的误差预期。**

对一次新测量，统计项已经压过改正项：各档自身的 68% 半宽除以 `k` 是 **0.36 / 0.45 / 1.33 mm**（轴心 / −8 mm / −16 mm），都比 0.163 mm 的改正残差大。**也就是说 mode (b) 现在是统计受限，不是刻度受限。**

### 5.3 对两种工作模式的影响

- **mode (a) 扫到中心**：仍然最准，偏差 −0.07 mm，68% 区间 [−15.40, −14.73]，即半宽 0.33 mm。

## 六、一个需要留意的现象：浅带对比度随离轴距离上升

```
0–8 带 c_b：  main(u=0) 2.40%   offset(u=−8) 3.75%   offset2(u=−16) 16.43%
```

0–8 带的拟合窗只有 ±16.5 mm，而 offset2 的边界恰好落在 `u = −16`，**就在窗口边缘**，拟合在那里本来就不稳（`w` 也从 2.26 涨到 4.50 mm）。所以 16.43% 这个数**不能**拿去和 main 档的 2.40% 直接比较，更不能用来推翻"浅带单次散射对比度为零"的结论——那条结论出自双比值诊断，与拟合窗无关。

**引用浅带数字时必须连边界位置一起写。**
