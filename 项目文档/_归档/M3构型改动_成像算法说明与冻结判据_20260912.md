## 三、成像算法说明（给导师的那份文档）

交付件 `deliverables/成像算法说明_20260912.docx`（另有同名 `.pdf`），11 节。核心内容：

### 两台探测器的分工（全文最容易搞混的一点）

| | D1 背散射探测器 | D2 标记探测器 |
|---|---|---|
| 形状 | GAGG 环，中心开孔 | 50×50 像素阵列 |
| 位置 | 贴近被测物体 | 源的上方远处 |
| 接住 | 物体里散射回来的光子（运动学范围 170–256 keV；能窗 **180–250 keV**） | 背靠背的另一个 511 keV 光子（能窗 400–600 keV） |
| 给出 | 命中点 `H` + 能量 `E'` → 散射角 θ | 命中点 `T` → 入射光子方向 |
| 能量分辨 | 8% @511 keV | **12%** @511 keV（需求文档写 15%，见文末勘误） |
| 位置分辨 | **1.55 / 1.55 / 5.0 mm**（需求文档写 1.5 / 1.5 / 5） | 1.0 / 1.0 / 2.5 mm |

> **2026-09-23 勘误**：上表 09-12 原文照抄了 docx，写的是 D2 "15% @511 keV（需求文档指定）"、D1 位置分辨 "1.5 / 1.5 / 5.0 mm"。那是导师需求文档的值，**不是仿真实际用的值**。仿真实际值取自 `configs\m3_edge_main_20260912.json`：D2 `fwhm_fraction_at_511 = 0.12`，D1 `position_response.resolution_mm = [1.55, 1.55, 5.0]`，D1 能窗 `[180, 250]` keV。M2 与 M3 全部运行都是这组值。**`成像算法说明_20260912.docx` 本身还没改。**本文件第四节的冻结判据不受影响。

### 冻结的四步流水线（顺序不可调换）

```
事件合成 → 探测器响应 → 可观测量筛选 → 闭式散射点重建
```

顺序一旦改动，之前所有的标定数字全部作废：先筛选再加响应会高估选出率；先重建再加响应等于偷看 GATE 真值能量。

### 闭式重建：解三角形，五行

```
cos θ = 2 − 511 / E'
v     = 由 D2 命中点 T 反推的单位入射方向
d     = H − S ,   α = arccos( v·d / |d| )
t     = |d| · sin(θ − α) / sin θ
P     = S + t · v
```

与"直线∩圆锥"二次方程 `t² − 2at + (a² − c²|d|²)/(1−c²) = 0` 数值完全等价（4000 事件、2088 有解，两法差值最大 **0.000000 mm**），但三角形解法**自动落在物理根上**，不需要 `sign(a−t) = sign(cos θ)` 这条额外判据。

### 5.4 两种解法的配图（2026-09-12 新增）

脚本 `scripts/make_reconstruction_figure.py`，画的是**同一个事件**的两种解法。为了把"伪根"讲透，事件参数是**构造**出来的一个自洽算例（`T = (−15, 52.5)`，`H = (30, 7.5)`，`θ = 120°` 即 `E′ = 204.4 keV`），**不是 GATE 实测事件**，图注里写明了：

- 正弦定理：`α = 48.4°`，`|d| = 31.62 mm` → `t = 34.65 mm`，`P = (13.65, −14.35)`
- 二次方程：`a = v·d = 21.01`，`c = −0.500` → **两个根都大于零**：`t1 = 34.65`、`t2 = 7.36`
- 所以**光靠 `t > 0` 去不掉伪根**，必须用 `sign(a − t) = sign(cos θ)`：`t1` 给 `−13.65`（同号，保留），`t2` 给 `+13.65`（反号，剔除）
- 伪根的几何含义：平方以后方程描述的是**半角 θ 与半角 180°−θ 两叶锥面的并集**，`P′` 落在 60° 那一叶上——在 `P′` 处 `v` 与 `P′→H` 的夹角是 60°，不是 120°
- 脚本里有断言把关"正弦定理的解必须等于二次方程的物理根"，实测差 7×10⁻¹⁵ mm

**一个踩过的坑（工具限制，值得记下来）**：doc 的 docx 导出器对插图尺寸有硬上限——实测（800×500 / 1600×1000 / 3040×2080 三种像素数，96 / 300 / 340 三种 dpi，1.25 / 1.50 / 0.67 / 2.14 四种宽高比）规律是**保持宽高比缩到最宽 3.12 英寸、最高 2.33 英寸为止**；像素数与 dpi 都不影响结果，`{w=...}` 属性 docx 导出器也不认，`::: page {orientation=landscape}` 也没生效。所以一张 15 英寸宽的详图塞进 docx 会被压到看不清。做法：**按 3.12 × 2.33 英寸重画两张紧凑版插进正文**（`closed_form_doc_a/b.png`），**大幅详图作为独立文件交付**（`outputs/closed_form_reconstruction.png/.pdf`，做 PPT 或打印用）。以后凡是要往 docx 里插图，先按这个上限设计画幅和字号。

### 为什么深度比横向差一个量级

`cos θ = 2 − 511/E'` 对 `E'` 求导在大角度处极度放大。8% @511 keV 下：

| θ | E' (keV) | σ(θ) |
|---|---|---|
| 90° | 255.5 | 5.51° |
| 120° | 204.4 | 8.88° |
| **150°** | 178.3 | **18.89°** |
| 180° | 170.3 | 538.90° |

端到端合成测试：**横向误差中位 1.91 mm，深度误差中位 11.38 mm**。

**这决定了整个项目的策略：不测空鼓深度，测空鼓的横向边界。**

### 判据不建立在图像上

MLEM 图像真值线内质量占比 67.5%（均匀期望 20%），但**真值深度带内只有 26.2%（期望 25%）**——深度方向基本不带信息。所以图像只是辅助材料，结论来自多深度带共享边界二项似然：

```
n_void | n_tot ~ Binomial(n_tot, ρ/(1+ρ))
ρ(x, b) = s · A_b · (1 − c_b · Φ((x − x_e)/w))      x_e、w 全带共享；A_b、c_b 每带自由
T = −2lnL(平坦) + 2lnL(带边界)
```

零分布用蒙卡标定而非渐近 χ²（`c_b = 0` 时 `x_e`、`w` 不可辨识，Wilks 前提不成立）。3000 次零试验：中位 8.0 / 99% 19.0 / 99.9% 27.2 / 最大 28.0 → **T_thr = 30**。

## 五、本轮相对 M2 必须多跑的一档：refnull

M2 的 `--ref-null` 用的是 `mural_ref_t10_L-15_2m_seed24091012`，那是 **M1 时期、旧几何**跑的底片。新构型下再拿它当底片，`refnull / ref` 的比值里会混进**几何差异**而不只是统计涨落，负对照（判据 3、4）会假报警，整套判据就废了。

所以 STAGE=a 加了 `refnull:120:200:120:24091303`——与 `ref` 的空鼓摆位逐字相同（都挪到 x = 200 mm 看不见），**只换随机种子**，是同一个物理场的两次独立实现。

**代价**：STAGE=a 从两档变三档。M2 两档 400 万事例实测 76 分钟，本轮按 **110~150 分钟**准备（STAGE=b 两档按 75~100 分钟）。

### 为什么判据 8 要单开一个 widefov 配置

M2 实测里最深的 25–35 带有效窗已经顶到 ±34.5 mm，也就是**被直方图边界截断而不是被物理截断**，在 ±36 mm 的窗里根本量不出 +19% 的视场增益。但箱数一变零分布就变，`T_thr = 30` 不再适用，M3 与 M2 的 `T` 也不能直接比。所以：**判据 1~7 与 9 全部在 ±36 mm 的原配置上做；判据 8 单独在 ±48 mm 的 `m3_edge_main_widefov_20260912.json` 上量宽度，那一跑用 `--null-trials 0`，`T` 一概不看。**
